新闻聚合平台，支持多 RSS 源与灵活过滤，接入本地 Ollama 做翻译与智能去重，同时提供 SQL 过滤、PostgreSQL 存储与 React 前端阅读/管理界面，适合自建新闻流或学习抓取、去重与前后端协同。  
技术：Rust、PostgreSQL、React、RSS、Ollama
